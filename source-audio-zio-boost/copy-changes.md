## Conflicts between sources, left as printed

- Footswitch bypass: the User Guide says "True Bypass" (Feature Overview, Specifications, Where Do I Put the ZIO?), while its FAQ speaks of "buffered bypass mode".
- TONE switch: the User Guide says BRIGHT restores top end lost to long cables; the card says TONE works "by adding capacitance to reduce high frequencies on very bright guitars".
- TUNER/LINE output with the LED off in BYPASS mode: only the card says "No Connection"; the User Guide is silent.
- Power: the card says "9V DC supply" with 18V possible for headroom; the User Guide gives 9-18V DC, regulated, 20 mA.

## Template leftovers kept as printed

- TUNER / LINE OUT: "It carries an audio signal when the ZIO is configured with a signal routing that uses stereo outputs." The ZIO has no routing configuration.
