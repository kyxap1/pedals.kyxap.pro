# NUX Loop Core Deluxe: copy changes

Source: `NUX_LoopCoreDeluxe_UserManual_English.pdf`, linked from the official
product page https://www.nuxaudio.com/product/loop-core-deluxe/ (download host
nux.cherubtechnology.com). It is byte-identical to the copy the user supplied.
The product page offers no other English document; the NUX Format Converter
download is software. The PDF has its text converted to outlines, so the copy
was OCR'd from 300-dpi renders, and every 7-segment display readout
(rd, rP, nr, Ar, St, Fn, FA, SA, FU, dL, F0, F3, F4, Lo) was read by eye.

## Template leftovers (jack names that contradict the panel)

| Section | Print | Page | Reason |
|---|---|---|---|
| Power ON/OFF | insert a plug into the OUT L jack | inserting a plug into the To Amp jack | the pedal has no OUT L; the figure shows the plug going into To Amp |
| 1.1.3 note | plug a cable in OUT L jack | plugging a cable into the To Amp jack | same |
| 1.2.2 | from AUX In or Input jack | from the Input jack | the pedal has no AUX In |
| 1.2.1, 1.4.1 | STOP MODE button / STOP MODES buttons | STOP/MODES button | panel label |

## Conflicts left as printed

- 2.5 and 2.6 both say they set "your desired tempo"; after 2.4 (the pattern number blinks), 2.5 most likely sets the pattern.
- 4. USB Connection: "will show “”", with the display readout missing from the print.
- RHYTHM button cites "(P12, P13)" for Applications 3 and 4, which are printed pages 10 and 11. The citation is replaced by anchor links.
