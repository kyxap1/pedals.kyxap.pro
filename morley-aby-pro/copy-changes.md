# Morley ABY Pro — copy changes

## Source

- `aby-pro-owners-manual-jan2019.pdf` — handed over by the user (PDF title
  "aby pro owners manual jan2019.ai", created 2019-01-16). morleyproducts.com
  sits behind a Cloudflare human check, so it could not be compared against
  the copy on the maker's site, and no extra documents were looked for there.
- Page style taken from a saved copy of a morleyproducts.com product page
  (20/20 Distortion Wah): Open Sans body, Raleway 600 caps headings, black
  header band, grey page-header strip, dark footer. The Morley wordmark is
  that page's logo file.
- Masthead photo: the pedal cut out of the manual's own Set Up Example image.

## Departures from the print

| Section | Print | Page |
|---|---|---|
| connections | `IN: Input jack.` | `INPUT` — the jack is labelled INPUT on the pedal, and the instructions say "Plug instrument into INPUT" |
| battery | `unplug your cord completely from the IN jack` | `… from the INPUT jack` — same reason |
| connections | `the 1/4” jacks` (curly quote) | `1/4"`, matching the other two lines |
| battery | one paragraph | three paragraphs (power, battery life, transformer draw) |
| battery | `"Quick Clip" Battery door` | curly quotes |
| features | `prevent any switch “pop” or “click”` | full stop added |
| instructions | `was designed  to` (double space) | single space |
| instructions | `Plug Instrument into INPUT` | `Plug instrument into INPUT` |
| instructions | `(TS - Tip/Sleeve)` | en dash |
| instructions | `LED’s show which amp` | `LEDs show which amp` |
| instructions | `(see Set Up Example)` | links to the Set Up Example heading |
| masthead | — | subtitle "Selector Combiner · Owner’s Manual": the instructions heading plus the PDF title ("owners manual") |
| intro, headings | ALL CAPS | sentence case in the HTML, shown in caps by CSS (headings) |

## Conflicts left as printed

- Dimensions: the manual gives 5.5" L x 3.5" W x 2.8" H; Morley's January 2019
  press release gives 5" x 3.38" x 2.75" (L x W x H).
