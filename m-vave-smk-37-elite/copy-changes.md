## Conflicts left as printed

- Function Overview and Panel Introduction say pitch and modulation **wheels**; the spec table calls them **touch strips**.
- Left Button opens functions "on the next page", Right Button "on the last page"; yet Globe + Right and Seq + Right both open the *next* page (factory reset, Clear Pattern).
- The text calls the arrow keys Left/Right Button; the panel labels the keys under them OCTAVE- / OCTAVE+, a function the text never describes.
- Back of Device lists "Power"; the jack drawing labels it SWITCH.
- Arpeggiator and Note Repeat screens show "Rate-55" and "Tempo-55", which don't match the rate divisions the text lists.
- Windows wireless requirement: "WIN10/11" (card), "Windows 10 or later" (MIDI Connection Method), "BT 5.0 and extra BLE MIDI Driver" (Direct MIDI Wireless).
- Screen says "Clean Pattern", text says "Clear Pattern".
- Wireless adapters A and B are described but not in the Packing List.
